# 🔐 Sistema de Login e Cadastro – PHP + SQLite

Este é um sistema simples e funcional de **login e cadastro de usuários**, desenvolvido em PHP com banco de dados SQLite. Ideal para projetos leves ou aprendizado de autenticação básica em aplicações web.

## ⚙️ Funcionalidades

- Cadastro de novos usuários
- Autenticação com verificação de login e senha
- Validação de campos (PHP)
- Banco de dados local com SQLite
- Sessão de login e redirecionamento seguro

## 🛠️ Tecnologias Utilizadas

- **PHP** (7.4+)
- **SQLite** (banco de dados local)
- **HTML5 + CSS3** (interface)
